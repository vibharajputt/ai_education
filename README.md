## Tech Stack

| Layer | Choice |
|---|---|
| Frontend | Vite 5, React 18, TypeScript 5 (strict) |
| Styling | Tailwind CSS v3 |
| Routing | React Router v6 |
| State | localStorage (no Redux) |
| Server | Express (2 live AI routes only) |
| AI | OpenAI-compatible API (server-side only) |
| Content | Static JSON pre-generated by `tools/` |

## Getting Started

### Prerequisites
- Node 20+
- An OpenAI-compatible API key (for server only)

### 1. Install dependencies

```bash
# Frontend
npm install

# Server
cd server && npm install
```

### 2. Configure environment

```bash
cp .env.example .env
# Fill in VITE_API_BASE_URL

cd server
cp .env.example .env
# Fill in AI_API_KEY, AI_MODEL, etc.
```

### 3. Generate content (offline, one-time)

```bash
# Requires AI_API_KEY set in tools/.env
node tools/generate.js
```

### 4. Run

```bash
# Terminal 1 — frontend dev server
npm run dev

# Terminal 2 — Express API
cd server && npm run dev
```

## Project Structure

```
/
├── src/
│   ├── app/          # Shell, router, layout, theme
│   ├── modules/      # 21 module folders — each exports a ModuleConfig
│   ├── core/         # types.ts, loaders, aiClient, shared hooks
│   └── components/   # Shared UI primitives
├── content/          # Pre-generated JSON (committed)
├── tools/            # Offline content-generation scripts + prompts
├── server/           # Express: /api/explain, /api/analyze-resume
└── public/
```

See [AGENTS.md](./AGENTS.md) for architecture decisions, content model, and team conventions.
